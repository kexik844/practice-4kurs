# API — Каталог услуг

Базовый адрес при локальном запуске: `http://127.0.0.1:8000/api/`.
Формат данных: JSON. Администратором считается пользователь с `is_staff=True`.

## Категории — `/api/categories/`

| Метод | Маршрут | Назначение | Доступ |
| --- | --- | --- | --- |
| GET | `/api/categories/` | Список категорий | Всем |
| POST | `/api/categories/` | Создать категорию | Администратор |
| GET | `/api/categories/{id}/` | Получить категорию | Всем |
| PUT | `/api/categories/{id}/` | Полностью обновить категорию | Администратор |
| PATCH | `/api/categories/{id}/` | Частично обновить категорию | Администратор |
| DELETE | `/api/categories/{id}/` | Удалить категорию | Администратор |

При создании категории передаётся `name`; `slug` генерируется автоматически.

## Услуги — `/api/services/`

| Метод | Маршрут | Назначение | Доступ |
| --- | --- | --- | --- |
| GET | `/api/services/` | Список услуг | Всем, только доступные для обычных пользователей |
| POST | `/api/services/` | Создать услугу | Администратор |
| GET | `/api/services/{id}/` | Получить услугу | Всем, если услуга доступна; администратор — любую |
| PUT | `/api/services/{id}/` | Полностью обновить услугу | Администратор |
| PATCH | `/api/services/{id}/` | Частично обновить услугу | Администратор |
| DELETE | `/api/services/{id}/` | Удалить услугу | Администратор |

### Параметры списка услуг

| Параметр | Пример | Описание |
| --- | --- | --- |
| `category` | `category=1` | ID категории |
| `is_available` | `is_available=true` | Доступность (`true` / `false`) |
| `min_price` | `min_price=1000` | Цена больше или равна указанной |
| `max_price` | `max_price=5000` | Цена меньше или равна указанной |
| `search` | `search=ремонт` | Поиск по названию и описанию |
| `ordering` | `ordering=price` | Цена по возрастанию |
| `ordering` | `ordering=-price` | Цена по убыванию |
| `page` | `page=2` | Номер страницы |
| `page_size` | `page_size=10` | Размер страницы (от 1 до 10, по умолчанию 5) |

Параметры можно сочетать. Без явной сортировки услуги упорядочиваются по ID.

```http
GET /api/services/?category=1
GET /api/services/?is_available=true
GET /api/services/?min_price=1000&max_price=5000
GET /api/services/?search=ремонт
GET /api/services/?ordering=price
GET /api/services/?ordering=-price
GET /api/services/?category=1&min_price=1000&max_price=5000&ordering=price&page=1&page_size=5
```

Обычный пользователь не может получить недоступные услуги даже при `is_available=false`.

Проверки при сохранении услуги: `price >= 0`, `duration_minutes > 0`.

## Заявки — `/api/requests/`

| Метод | Маршрут | Назначение | Доступ |
| --- | --- | --- | --- |
| GET | `/api/requests/` | Список заявок | Администратор |
| POST | `/api/requests/` | Создать заявку | Всем |
| GET | `/api/requests/{id}/` | Получить заявку | Администратор |
| PUT | `/api/requests/{id}/` | Полностью обновить заявку | Администратор |
| PATCH | `/api/requests/{id}/` | Частично обновить заявку | Администратор |
| DELETE | `/api/requests/{id}/` | Удалить заявку | Администратор |

Пример тела POST-запроса:

```json
{
  "service": 1,
  "client_name": "Иван Иванов",
  "phone": "+79990000000",
  "desired_at": "2027-01-15T15:00:00+03:00"
}
```

Услуга должна существовать и быть доступной, телефон — корректным, желаемая дата — в будущем на момент отправки. Статус новой заявки устанавливается сервером: `new`. Допустимые статусы при административном редактировании: `new`, `confirmed`, `completed`, `cancelled`.

## Пагинация

Применяется к спискам категорий, услуг и заявок при глобальной настройке `StandardPagination`. По умолчанию возвращается до 5 объектов, через `page_size` можно запросить до 10. Последняя страница может содержать меньше объектов. `count` — общее количество записей с учётом прав доступа и фильтрации.

Пример структуры ответа (условные данные):

```json
{
  "count": 1,
  "next": null,
  "previous": null,
  "results": [
    {
      "id": 1,
      "category": 1,
      "name": "Ремонт ПК",
      "description": "Диагностика и ремонт компьютера",
      "price": "1500.00",
      "duration_minutes": 60,
      "is_available": true,
      "created_at": "2026-11-24T09:00:00+03:00"
    }
  ]
}
```

## Коды ответа

| Код | Значение |
| --- | --- |
| 200 | Успешное чтение или обновление |
| 201 | Запись создана |
| 204 | Запись удалена |
| 400 | Ошибка валидации |
| 401 / 403 | Необходима авторизация или недостаточно прав |
| 404 | Объект или страница не найдены (в том числе скрытая услуга для обычного пользователя) |

## Дополнительные маршруты

- `/api/` — корневой список маршрутов DefaultRouter.
- `/admin/` — административная панель Django.
- `/api-auth/login/` — вход в browsable API DRF при подключении `rest_framework.urls`.
- `/api-auth/logout/` — выход из browsable API DRF.
